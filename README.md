# Link Validator

Automatically validates links in JSON files and tracks broken links.

## Features

- 🔍 Recursively scans JSON files for URLs
- 🚀 Concurrent validation for speed
- 🔄 Automatic retries for failed requests
- 📊 Generates detailed broken links reports
- ⏰ Runs daily via GitHub Actions

### Manual Run
```bash
